# opencode-shim

An [opencode](https://opencode.ai) plugin that lets opencode consume the artifacts you already
maintain for **Claude Code** and **GitHub Copilot** — skills, MCP servers (`.mcp.json`),
agents, prompts/commands, instructions — so a team mixing all three tools keeps one set of
files instead of three.

Status: bootstrapping. See the issues for the plan.
